# CHURN-PREDICTION-ML

📌 Project Overview

This project focuses on building a machine learning model to predict whether a customer is likely to churn (leave the service) based on their usage patterns, service details, and account information.
The model helps telecom companies take proactive retention measures by identifying high-risk customers in advance.

🎯 Objectives

Analyze telecom customer data
Perform data preprocessing and feature engineering
Build and evaluate churn prediction models
Generate insights from actual vs predicted churn

🛠️ Technologies Used

Programming Language: Python
Environment: Google Colab / Jupyter Notebook
Machine Learning Model:xgboost
Libraries:
        NumPy
        Pandas
        Matplotlib
        Seaborn
        Scikit-learn

📂 Dataset

Telco Customer Churn Dataset
Churn Label:
          1->churn
          0->stay

🔄 Project Workflow

Data Loading
Exploratory Data Analysis (EDA)
Data Cleaning & Encoding
Feature Selection
Model Training
Model Evaluation
Churn Prediction & Visualization

📊 Evaluation Metrics

Accuracy
Precision
Recall
F1-Score
Confusion Matrix

📈 Results

The trained model successfully predicts customer churn with good accuracy.
Visualization of Actual vs Predicted Churn provides insight into model performance.
Important features influencing churn are identified.
